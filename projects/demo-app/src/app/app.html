GETTING STARTED WITH NGX-SKELETON

Renderer-agnostic structural directive suite for Angular 18+. Ship skeletons with native CSS, PrimeNG, or Angular Material renderers. Eliminate repeated template boilerplate, prevent layout shifts (CLS), and enforce design system precision.

STEP 01

NPM INSTALLATION

Install the package via npm or yarn into your Angular workspace:

npm install ngx-skeleton-suite
DEPENDENCY MATRIX

• Angular Core: >= 18.0.0 < 23.0.0

• RxJS: >= 7.4.0

• PrimeNG (optional adapter): >= 17.0.0 < 24.0.0 (match your Angular major)

• ngx-skeleton-loader (optional Material adapter): >= 11.0.0

STEP 02

STANDALONE COMPONENT SETUP

Import SkeletonDirective directly into standalone Angular components:

import { Component, signal } from '@angular/core';
import { SkeletonDirective } from 'ngx-skeleton-suite';

@Component({
  selector: 'app-user-profile',
  standalone: true,
  imports: [SkeletonDirective],
  template: `
    <div *skeleton="isLoading(); height: '12rem'; animation: 'wave'">
      <app-user-card [user]="user()" />
    </div>
  `
})
export class UserProfileComponent {
  isLoading = signal(true);
}

STEP 03

GLOBAL PROVIDER CONFIGURATION

Configure application-wide default animation modes, delay timers, and custom preset registries in app.config.ts:

import { ApplicationConfig } from '@angular/core';
import { provideNgxSkeleton } from 'ngx-skeleton-suite';

export const appConfig: ApplicationConfig = {
  providers: [
    provideNgxSkeleton({
      animation: 'wave',
      delayMs: 80,
      minimumDurationMs: 200,
      fadeInMs: 180,
      preserveLayout: true,
    }),
  ],
};
STEP 04

RENDERER ADAPTERS

By default ngx-skeleton-suite renders dependency-free native CSS skeletons. Install and register a renderer adapter only when you need it:

// Native CSS (default) — no extra dependencies
import { provideNgxSkeleton } from 'ngx-skeleton-suite';

// PrimeNG adapter
import { providePrimeNgSkeleton } from 'ngx-skeleton-suite/primeng';

// Material adapter (based on ngx-skeleton-loader)
import { provideMaterialSkeleton } from 'ngx-skeleton-suite/material';

export const appConfig: ApplicationConfig = {
  providers: [
    provideNgxSkeleton({ animation: 'adapter-default' }),
    providePrimeNgSkeleton(), // or provideMaterialSkeleton()
  ],
};

THEMING

01. CSS CUSTOM PROPERTIES

Override CSS custom properties globally at :root or per theme selector without using !important:

/* styles.scss */
:root {
  --ngx-skeleton-base-color: #1e293b;
  --ngx-skeleton-highlight-color: rgba(255, 255, 255, 0.15);
  --ngx-skeleton-animation-duration: 1.4s;
  --ngx-skeleton-fade-duration: 180ms;
}

[data-theme='light'] {
  --ngx-skeleton-base-color: #e2e8f0;
  --ngx-skeleton-highlight-color: #ffffff;
}

03. FLEXBOX & STACK ALIGNMENT

Control horizontal and vertical alignment in custom shape presets:

export const ALIGNED_HEADER_PRESET: SkeletonPreset = {
  name: 'aligned-header',
  shapes: [
    {
      type: 'stack',
      direction: 'row',          // Horizontal alignment
      alignItems: 'center',       // Vertical centering
      justifyContent: 'space-between',
      gap: '1.5rem',
      children: [
        { type: 'shape', shape: 'circle', size: '3.5rem' },
        { type: 'shape', width: '60%', height: '1.25rem' }
      ]
    }
  ]
};
