## Key Features

<CardGrid stack>
  <Card title="Renderer Adapters" icon="puzzle">
    Dependency-free **native CSS** by default. Opt into **PrimeNG** or **Angular Material** renderers, or add your own via the documented `SkeletonRendererComponent` contract.
  </Card>
  <Card title="Zero-CLS Layout Preservation" icon="star">
    Automatically measures real component bounding boxes before loading and reserves height/width, preventing Cumulative Layout Shift (CLS).
  </Card>
  <Card title="7 Built-in Composite Presets" icon="puzzle">
    Instant complex shapes: `card`, `profile-card`, `avatar`, `list-item`, `paragraph`, `table-row`, and `image-card`.
  </Card>
  <Card title="Dynamic CSS Grid Engine" icon="grid">
    Generate multi-column skeleton grids on the fly with `auto-fit` minimum widths or responsive breakpoint objects (`{ sm: 2, md: 4, lg: 6 }`).
  </Card>
  <Card title="Universal Async & Signal Binding" icon="rocket">
    Seamlessly unwrap Promises, RxJS Observables, and Angular Signals directly via directive microsyntax `*skeleton="let user from user$"`.
  </Card>
</CardGrid>

## Quick Installation

```bash
npm install ngx-skeleton-suite
```

The built-in **native CSS renderer** needs no UI library. To render with a UI framework,
install its adapter peer and register the provider:

```bash
# PrimeNG adapter (use the PrimeNG major matching your Angular major)
npm install primeng
# Material adapter (community package)
npm install ngx-skeleton-loader
```

```typescript
// app.config.ts
import { ApplicationConfig } from '@angular/core';
import { provideNgxSkeleton } from 'ngx-skeleton-suite';
import { providePrimeNgSkeleton } from 'ngx-skeleton-suite/primeng';

export const appConfig: ApplicationConfig = {
  providers: [provideNgxSkeleton(), providePrimeNgSkeleton()],
};
```

```typescript
import { Component } from '@angular/core';
import { SkeletonDirective } from 'ngx-skeleton-suite';

@Component({
  standalone: true,
  imports: [SkeletonDirective],
  template: `
    <div *skeleton="isLoading; preset: 'card'">
      <app-user-card />
    </div>
  `
})
export class UserComponent {
  isLoading = true;
}
```
